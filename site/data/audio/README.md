Optional local audio goes here. The empty manifest keeps the game silent.

Map cue names to filenames in `manifest.json`, for example `"whisper": "whisper.ogg"`.
Supported extensions: mp3, wav, ogg, m4a. Filenames may contain letters, numbers,
underscores, and hyphens. Use recordings you own.

Cues: `whisper`, `pen`, `curtain`, `page-turn`, `narrator-1` through `narrator-6`.
The mute control enables sound after a user gesture. Missing cues stay silent.
